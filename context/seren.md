# Seren

- [E] An autonomous system they let run with substantial independence.
- [E] Idea: automatically write a blog on a topic, like a tech watch. "Seren" is for serendipity. (2026-09-30)
- [E] They built one instance on bio AI, and it works "very well": they say they now have a good tech watch. (2026-09-30)
- [E] Two kinds of workflow runs, each fired every day: (2026-09-30)
  - **Explore:** searches the internet for news related to the defined theme and maintains a knowledge base. One report per day over the last 6 months, plus two buffer memory files, one covering the last month and one the last 6 months.
  - **Publish:** reads the knowledge base and the memory files, decides whether to write a new article, and usually produces one.
- Not yet recorded: when it was built, whether the articles are published anywhere, how much they intervene. Ask before using.
