# The easier an environment is to set up, the sooner the work is replaced

## Current understanding
Their answer to "what will AI replace?" (students' question): what gets
replaced is decided by how easy it is to set up the environment for the
agent. The easier the environment, the more the work will be replaced.

This reads directly on `agent-gets-an-environment` (agent = chatbot +
environment): the model is the same everywhere, so the limit is the
environment around it. Link is the agent's reading, consistent with their
picture, not stated.

Their examples (2026-10-23): a lawyer or a doctor. For them, the
environment those jobs need is basically a connection to a knowledge base,
so it is easy to set up. That runs against the common view that high-status,
long-training professions are the safest: by this measure the length of the
training does not protect, the shape of the environment does.
(The contrast with the common view is the agent's framing, not theirs.)
