# Shared memory across agents and people

## Current understanding
Started as a dating/matrimonial agent, became a general social assistant,
then a social MCP, then a much simpler shared-memory MCP. Two drivers:
personal memory shouldn't be locked to one model (switching from ChatGPT to
Claude without losing context), and closed groups (couples, families,
project teams) could share memory. Rejects the idea that assistants are only
for work productivity. Privacy is an acknowledged, unresolved problem.
