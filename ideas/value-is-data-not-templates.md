# The value is the data, not the template

## Current understanding
Comparing Wada and Kura: the reusable shell (a template, a workflow) is easy
to produce, and anyone can make their own. Curated, structured context is
the scarce part, and that's where the value is.

## Open threads

- What makes data "curated" enough to be worth something?
