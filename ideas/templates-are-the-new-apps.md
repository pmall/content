# Templates are the new apps

## Current understanding
A model for where software value moves: structured environments and
data/context matter more than conventional application UI. "Template" = a coding agent + markdown files assisting in one field (this repo is one). Related
inversion: instead of an MCP connecting to an application, the MCP *is*
the application.
